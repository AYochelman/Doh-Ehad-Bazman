# דוח 1 בזמן

כלי לתזמון ותזכור של דוח 1 דרך וואטסאפ. אפליקציית רשת שמוסיפים למסך הבית של הטלפון.

- הודעות מוכנות, עם `{שם}` שמוחלף בשם הנמען
- אנשים ומספרים עם שמות, בלי לשמור אותם באנשי הקשר של הטלפון
- ייבוא מספרים מהדבקת רשימה או מתמונה (צילום מסך של אקסל)
- רשימות תפוצה
- תזמון חד פעמי או קבוע: יומי, שבועי, חודשי, שנתי
- שיתוף אנשים, רשימות והודעות עם קולגות

## איך זה שולח

האפליקציה לא שולחת לבד. בזמן שנקבע היא מציגה את ההודעה מוכנה, ולחיצה פותחת את וואטסאפ עם הטקסט; את "שלח" לוחצים בוואטסאפ.

## פרטיות

אין שרת. כל המידע נשמר בדפדפן של המכשיר (`localStorage`). קריאת התמונות נעשית במכשיר; מנוע הקריאה (tesseract.js) יורד מ-jsDelivr בשימוש הראשון.

## פיתוח

קובץ אחד, `index.html`, בלי שלב בנייה. פותחים אותו בדפדפן.
